## 2. Workstream A · 地区识别修复（今天，最高 ROI）

**问题定位**：两处 SQL 旧实现只认「国家名 + 固定城市白名单」，不认美国州代码，也不去噪：
- `public.job_region_matches_target(region)` → 决定 `matches_target_region`（目录默认可见性、AI 选岗候选、索引）
- `public.ai_match_region_scope(region)` → 决定 `region_market`（地区筛选）和 `job_ai_match_scopes`（AI 检索）

两处都有对应触发器（`jobs_sync_matches_target_region` BEFORE、`jobs_sync_ai_match_scope` AFTER），所以**只改函数 + 重跑一次 UPDATE 就能全量生效**，不需要改写路径代码（这一点比预想的简单）。
