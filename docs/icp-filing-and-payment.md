## 你必须先准备的材料

支付必须是 **企业或个体户**。个人主体做 ICP 过不了微信网站支付。

1. 营业执照原件彩照（有效期 > 1 年；上海管局要求）。
2. 法定代表人身份证原件正反面彩照（有效期 > 3 个月）。
3. 对公银行账户（企业）或法人对私账户（个体户）。
4. 大陆 +86 手机号、能收验证码，审核电照会打这个号。
5. 腾讯云账号：企业实名与营业执照一致，且这台轻量在该账号下。
6. 域名：所有者必须是 **公司中文全称、拼音全称或法定代表人姓名**；有效期 > 3 个月；完成实名认证。
7. 公章（个体户上海不支持无公章备案）。

不要把网站内容写成「招聘中介」。本站按 **信息技术服务 / 职业咨询** 来写，避免人力资源许可证和新闻/教育前置审批。

## 第一步：买域名并完成实名（你来做）

1. 在腾讯云或已实名的国内注册商买域名，优先 `.cn`。
2. 域名实名认证主体 = 营业执照名称或法人姓名。
3. **先不要解析到 `115.159.38.86`。** 备案申请阶段一般用域名所有权核验，不需要先指过来。
4. 保存域名证书 / 实名认证截图（含域名、所有者、证件号、到期日）。

把域名告诉我之后，我可以改 Nginx 的 `server_name`，并在备案通过后申请 HTTPS。

## 第二步：腾讯云提交 ICP 备案

入口：微信扫 [腾讯云 ICP 备案小程序](https://cloud.tencent.com/document/product/243/37402)，登录购买这台轻量的腾讯云账号。

建议按 **单位首次备案** 填：

1. 备案地区：营业执照登记省（企业必须与证件省份一致，不是服务器所在地）。这台机器在上海，只影响「接入/服务器放置地」，**备案号前缀跟公司注册地走**（广东是粤 ICP 备，上海是沪 ICP 备）。
2. 备案性质：企业 / 个体工商户。
3. 应用服务类型：网站/域名。
4. 网站域名：刚买的国内域名，不要填 `liorvix.com`。
5. 资源类型：选这台轻量应用服务器。需包年包月、购买时长 ≥ 3 个月、备案期间剩余有效期 ≥ 1 个月。
6. 网站名称：`liorvix求职服务平台`（与管局备案信息保持一致）。
7. 服务内容：选信息技术 / 其他，不要选新闻、教育、招聘中介。
8. 前置审批：以上都不涉及。
9. 主体负责人：法定代表人。网站负责人若不是法人，上海要额外传 [ICP 负责人授权书](https://cloud.tencent.com/document/product/243/14968)。
10. 通信地址写到门牌号；不要写「市辖区」。
11. 视频核验：网站负责人本人、大陆微信、白墙、所在定位与备案省份一致。审核电机会再打一次，保持手机畅通。

初审（腾讯云，大约 1 个工作日）→ 管局审核（常见 1–20 个工作日，上海波动较大）。驳回按小程序提示改材料后重新提交。

## 第四步：申请微信、支付宝商户

官网能公网打开、ICP 能在工信部查到之后再申请。类目建议选软件服务 / 在线信息服务，不要选人力资源中介。

### 微信支付（对应现有 Native / H5）

1. 用营业执照在 [微信支付商户平台](https://pay.weixin.qq.com/) 申请商户号。
2. 准备：营业执照、法人身份证、对公账户、已备案官网截图。
3. 开通 **Native 支付**（电脑扫码，我们现在的桌面结账）。
4. H5 支付审核更严，可能要求经营性 ICP 许可证；第一阶段可以先只开 Native。
5. 商户平台绑定 AppID，配置 APIv3 密钥、商户私钥、平台证书。
6. 回调 URL 填美国站：`https://liorvix.com/api/payments/wechat/notify`（先不要改国内站）。

### 支付宝（对应现有扫码 / WAP）

1. 企业支付宝实名后到 [支付宝开放平台](https://open.alipay.com/) 创建网页应用。
2. 签约电脑网站支付或当面付（扫码）。网站必须已备案，主体与支付宝账号一致。
3. 配置应用公钥、支付宝公钥、网关 `https://openapi.alipay.com/gateway.do`。
4. 异步通知：`https://liorvix.com/api/payments/alipay/notify`。
5. 同步跳转可先用 `https://liorvix.com/account/billing`。

审核常卡在：网站打不开、没有价格、没有售后说明、备案主体和商户主体不一致。本站首页已经放了方案价格和售后邮箱。

## 第五步：把密钥写进美国生产（你明确说之后我再做）

不要把密钥提交 Git，也不要写进这台备案机。

美国服务器 `/opt/liorvix/.env.local` 最终需要：

- `WECHAT_PAY_MCH_ID` / `WECHAT_PAY_APP_ID` / `WECHAT_PAY_SERIAL_NO` / `WECHAT_PAY_PRIVATE_KEY` / `WECHAT_PAY_API_V3_KEY` / 平台证书
- `WECHAT_PAY_NOTIFY_URL=https://liorvix.com/api/payments/wechat/notify`
- `ALIPAY_APP_ID` / `ALIPAY_PRIVATE_KEY` / `ALIPAY_PUBLIC_KEY`
- `ALIPAY_NOTIFY_URL=https://liorvix.com/api/payments/alipay/notify`
- `ALIPAY_RETURN_URL=https://liorvix.com/account/billing`

开关顺序：先只开一个渠道的 `*_ENABLED=true` 和 `BILLING_ENABLED=true`，小额实付、取消、超时、退款都跑通后再开第二个渠道。
