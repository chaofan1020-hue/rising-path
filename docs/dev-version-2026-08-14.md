# Dev 版本说明：2026-08-14

## 版本概述

本版本围绕海外留学生求职主流程做了集中更新，覆盖 ATS 简历优化、求职方向测评、个人求职驾驶舱、自动网申/申请管理，以及相关的数据库迁移和自动化测试。

驾驶舱部分曾尝试过深色科技感、浅色 shadcn 后台等设计改版，最终已回退到原有驾驶舱版式；本说明以最终回退后的状态为准。

## 模块与更新

### 1. ATS 简历优化

- 原简历展示优化：新优化记录保存结构化原简历 `original_data`，历史旧记录读取时按关联简历画像自动补齐。
- 逐条审核重构：技能、证书、经历、项目、教育支持结构化回退；拒绝后简历内容真实回退，接受保持内容不变，撤销拒绝可重新应用。
- 评分对比格式兼容：兼容 AI 返回 `original_resume / optimized_resume` 或直接返回评分对象等多种结构。
- 结构化编辑：优化结果支持在保持简历版式不变的前提下直接编辑姓名、联系方式、简介、技能、经历、教育、项目、证书。
- 修复优化结果弹窗无法下滑的问题。

### 2. 求职方向测评

- 新增 30 道测评题库，每次随机抽取 12 道，并保证五个维度配额：分析型 3、创意型 2、人际型 3、执行型 2、风险偏好 2。
- 新增具体岗位推荐引擎，覆盖 24 个细分方向，包括前端、后端、全栈、SDE、数据工程、数据分析、商业分析、BI、数据科学、机器学习、量化、风险、投行、金融、审计、咨询、产品、运营、供应链、市场、增长、UX、产品设计等。
- 岗位推荐结合性格维度、专业、技能、经历计算，输出 5 个方向：3 个高匹配方向 + 2 个签证友好备选。
- Sponsor 信息基于岗位库中已标注 `yes / no` 的岗位按方向和地区聚合，标签不足时显示“暂未明确”。
- 测评结果写入 `resume.profile.personality`，成为求职画像的一部分。
- 简历页只展示性格类型和五个维度分数；完整方向建议在驾驶舱展示。
- 新增 `GET/POST /api/personality/assessment`，并修复 sponsor 统计全表查询超时的问题。

### 3. 个人求职驾驶舱

- 驾驶舱 API 从简历画像读取 `personality`，不再单独依赖测评表。
- 求职路线诊断中展示方向岗位建议、sponsor 标签和签证友好备选。
- 驾驶舱板块顺序调整为：当前阶段 → 求职路线诊断 → 核心数据 → 求职规划 → 行动建议/提醒/面试评估 → Networking → 成长故事线。
- 最终保留原有驾驶舱视觉，不再保留临时设计改版。

### 4. 自动网申 / 申请管理

- AI 求职档案保存增加 `onConflict: 'user_id'`，避免重复记录。
- 申请记录列表增加“优化简历”入口，可从申请直接跳转到对应岗位的简历优化。

### 5. 数据库迁移

- `0017_allow_applications_without_resume.sql`：允许申请记录不绑定简历。
- `0018_resume_optimizations_original_data.sql`：优化记录增加结构化原简历字段。
- `0019_personality_assessments.sql`：新增用户最新求职方向测评表。

### 6. 文案与测试

- 补充简体中文、繁体中文、英文三套文案，覆盖测评、岗位、sponsor、方向建议等。
- 新增 `scripts/test-personality.ts`，覆盖随机抽题、配额校验、评分归一化、具体岗位推荐、sponsor 统计。
- 更新 `scripts/test-phase4.ts`，覆盖结构化审核回退与重新应用。
- 新增 `pnpm test:personality` 脚本。

## 验证

```bash
pnpm.cmd validate
pnpm.cmd test:personality
pnpm.cmd test:phase4
```

## 合并注意事项

- 本版本包含数据库迁移文件，合并后需要在目标环境执行新增迁移。
- 测评相关功能依赖 `personality_assessments` 表，未执行迁移前测评接口会报错。
- 驾驶舱设计改版已回退，合并时以最终回退后的 `src/app/dashboard/page.tsx` 为准。
- 旧测评结果可继续展示；重新测评后才会生成 24 个具体岗位和 sponsor 信息。
